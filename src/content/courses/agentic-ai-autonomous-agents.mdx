## Agents that actually work

Agents are powerful — and easy to get wrong. This course starts from first principles so you understand what's happening inside the agent loop, then builds up to stateful, tool-using agents with **guardrails, approvals and evaluation** built in from day one.

You'll finish with agents that complete real multi-step tasks, and the judgement to know when an agent is — and isn't — the right tool.
